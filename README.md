# Astra Reads

Explorer Cases: interactive phonics stories starring Finn and Zeb, for a Year 2 reader at Little Wandle Phase 5.

- One vowel sound per story, three spellings, underlined on the page. Tap any word to hear it and see its sound buttons.
- Two or three choices per story, including a Big Question with no right answer.
- A Case File of real facts, four comprehension questions (Blank's levels 1 to 4), a debrief and a patch.
- Four series, planned at ten chapters each: Time Travellers, Space Explorers, Wildlife Explorers, Ocean Explorers.

Static site, no build step. See `PLAN.md` (what and why), `CLAUDE.md` (how to work on it), `DEPLOY.md` (tablet and publishing), `research/` (sources).
